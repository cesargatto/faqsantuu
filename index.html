O print abaixo é um exemplo clássico. O usuário clicou para colocar uma Imagem Adicional mas não subiu nenhuma foto nesse quadrinho.
Quando isso acontece vai ficar num looping infinito e não vai ser enviado as imagens. Sempre que alguém tiver com problemas de looping infinito ao enviar imagens, verifique sempre se TODOS os quadrinhos foram adicionados imagens, deve sempre estar com o visto verde ✅
Os campos de nota fiscal e número de série também devem estar preenchidos. Verificar também se o usuário está logado.

Às vezes pode aparecer casos de o Carrinho estar Vazio.
Para isso é necessário verificar todos os dados cadastrais e do seguro, minuciosamente. Estando tudo ok, verifique o status desse seguro. Caso o status esteja como Recusada pelo ciclista, solicite que o ciclista entre em Minhas cotações e clique em Adicionar ao carrinho, dar F5 tentar de novo.
Caso o status esteja em Aguardando pagamento e todos os dados estiverem ok, não tem jeito, tem que abrir chamado (anexar sempre as evidências no chamado).

Antes de tudo verifique com atenção no print.
Repare que nesse caso o usuário digitou o próprio nome no CVV, sendo que aí deve estar preenchido os 3 dígitos do cartão. Às vezes na data de vencimento do cartão a pessoa digita um número, tipo 10. Mas nesse campo deve estar a validade do cartão, no padrão mm/aaaa (Ex: 12/2030) Se todos os dados do print estiverem ok, verifique no id do seguro se falta algo, um número de série, alguma foto pendente, um cupom vencido, se o seguro foi criado há mais de 15 dias.
Verificar também os dados cadastrais do ciclista.
Se tudo estiver ok, não tem jeito, tem que abrir chamado.

Minhas cotações aparecem todas as propostas que AINDA não foram emitidas.

Caso a proposta (apólice) já tenha sido Emitida, ir em Minhas compras e escolher a opção desejada.

Detalhe: Minhas compras é a mesma coisa que Seguros vendidos (só que este último é dos perfis de Vendedor e Corretor.)
